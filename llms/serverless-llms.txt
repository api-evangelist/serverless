# Serverless

> Serverless, Inc. builds the Serverless Framework — the original, leading tool for building, deploying and operating serverless applications on AWS Lambda and other managed cloud services. It pairs a YAML-configured, multi-language CLI with a Dashboard for monitoring and CI/CD, a plugin ecosystem, and an MCP server for AI-assistant access to infrastructure metrics, configuration and logs.

## Docs
- [Documentation](https://www.serverless.com/framework/docs): Serverless Framework documentation.
- [Getting Started](https://www.serverless.com/framework/docs/getting-started): Install and deploy your first service.
- [CLI Reference](https://www.serverless.com/framework/docs/providers/aws/cli-reference): Full command surface for the serverless CLI.
- [v4 Upgrade Guide](https://www.serverless.com/framework/docs/guides/upgrading-v4): Migrating to Serverless Framework v4.

## Tools
- [Serverless CLI (npm)](https://www.npmjs.com/package/serverless): `npm install -g serverless` — the framework CLI.
- [Dashboard Plugin (npm)](https://www.npmjs.com/package/@serverless/dashboard-plugin): Monitoring, CI/CD and secrets integration.
- [MCP Server](https://www.serverless.com/framework/docs): `serverless mcp` — local MCP server (stdio/HTTP/SSE) exposing infrastructure metrics, config and logs to AI assistants.
- [Dashboard](https://app.serverless.com): Monitoring, CI/CD and observability for serverless apps.
