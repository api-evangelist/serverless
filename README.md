Serverless, Inc. builds the Serverless Framework, the original and most widely adopted open-source tool for building, deploying and operating serverless applications on AWS Lambda and other managed cloud services. It pairs a YAML-configured, multi-language command-line interface with a Dashboard for monitoring and CI/CD, a large plugin ecosystem, and an MCP server that gives AI assistants access to infrastructure metrics, configuration and logs across Serverless Framework, AWS CloudFormation and SAM stacks. The company is based in San Francisco and backed by Lightspeed Venture Partners and Trinity Ventures.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Serverless: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
